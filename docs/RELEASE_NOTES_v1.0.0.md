# midEditor v1.0.0

> 类 Word 2003 / 旧版 Visual Studio 的 **MDI 文档型 MIDI 编辑器**：一个主窗口 + 多个文档子窗口，
> 每个子窗口是一个多音轨 MIDI 工程，核心编辑对象是**平行线**（沿横轴延伸的普通条，而不是圆角音符块）。

给「脑子里有旋律、但不想学五线谱和宿主软件」的人用的：双击空白处画一条平行线就能听，改长改短就是改时值。

---

## 亮点

### 平行线就是音符
- 画一条平行线 = 一个音；**粗细 = 力度**（velocity），拖动主体改时间/音高，拖右端改长度。
- 多音轨并排显示，每轨有独立可见音域窗口（12–128 半音，Ctrl+滚轮以鼠标处音高为锚点缩放）。
- 吸附：自动贴网格，也会贴到同音轨相邻平行线的两端。

### 休止符不是装饰，是「空隙」本身
- 第一个音开始之后、最后一个音结束之前，每一段没有声音的时间都会自动实体化成**红色线段**。
- 它和平行线**完全同级**：可框选、可单击、可拖动（后面的音整体推开/拉近）、可调长短、**可锁定**、可删除（后面的音自动提上来补齐）、可撤销、可存盘。
- 把空隙填掉，休止符就自己消失——不需要「手工插休止符」这种仪式。

### 收尾锁定
- 选中若干平行线 → 收尾锁定：按时间首尾相连，锁点画空心圆。
- 之后拖动 / 移动任意一条，整组一起动。
- **缩放不会传染**：拉长 A 的右端，锁点不动，被锁的 B 只整体平移贴回锁点，长度不变。

### 长度四键（统一语义）
| 按键 | 效果 | 不动的那一侧 |
| --- | --- | --- |
| `Ctrl+→` | 右端向右（外扩） | 左端 |
| `Ctrl+←` | 左端向左（外扩） | 右端 |
| `Shift+→` | 左端向右（内收） | 右端 |
| `Shift+←` | 右端向左（内收） | 左端 |
| `←/→` | 整体平移一格 | 长度不变 |

同时选中相邻的几条时按「整体」处理，只动最外侧那一条的边；收到 1 tick 为止，不会变成负数。

### 其他
- **MDI 多文档**：新建/打开的子窗口默认最大化，可层叠 / 平铺 / 全部还原；撤销栈**按文档隔离**。
- **拖拽打开**：把 .mid / .midi 直接拖进窗口（可多个）。
- **循环条**：标尺顶部一条窄带，拖空白=新建、拖中间=平移、拖两端=改边界、双击=关闭；也可以「循环=选区」。
- **滚轮语义统一**：裸滚轮=上下滚频谱；Shift=左右滚；Alt=时间缩放；Ctrl=音高缩放（都以鼠标处为锚点）。
- **Do（C）高亮**、键盘标尺、播放头跟随、节拍器、单击试听。
- 中文界面，暗色主题。

## 文件保真（v1.0 重点）

- 弯音（Pitch Bend）、RPN 粗/微调音、延音踏板、通道压力等**不建模的通道事件原样保存并参与回放**。
- 版权、调号、标记、乐器名等**外来 meta 事件原样带回**（不被吞掉）。
- **bank select（CC0/CC32）写在 program change 之前**，所以合成器音色选择与外部软件一致。
- 每轨可见音域窗口、休止符都写成自定义 text meta（`mideditor:yRange=` / `mideditor:rest=`），**重新打开视图不漂移、休止符不丢**。
- 明确已知的无损边界：音符释放力度、通道重新映射、拍号事件的填充字节、SMPTE 时间码等不会保留。

## 性能

- 长文件已线性化：2 万音符下一次编辑 / 一次完整拖拽都是毫秒级；按时间顺序建 5 万音符约 20 ms（此前 1.9 s）。
- 绘制的局部重绘只刷播放头附近窄带；长文件滚动、播放都稳定。
- 仍有 O(n) 的两项：撤销采用全量快照、每次编辑重建一次播放计划——十万级音符时才会成为下一个瓶颈。

## 质量

- **86 项自动化测试**：tick/微秒换算、.mid 往返（音域窗口 / 弯音与 RPN / 休止符 / 外来 meta / bank 顺序）、覆盖确认、
  撤销栈隔离、命令快捷键与启用态、MDI 多文档、编辑工作流、播放引擎（停止不余音、换计划不漏音、静音轨不漏响）、
  频率轴缩放、拖拽吸附、循环域与方向键、长度四键语义、收尾锁定、自动休止符、绘制回归、长文件性能。

## 运行要求

- **JDK 21+**（在 JDK 21.0.11 上验证），Windows 桌面。
- 音频：Gervill `SoftSynthesizer` + 系统 GM 音色库 `C:\Windows\System32\drivers\gm.dls`（Roland GS，235 个乐器）。
  也可放 `soundfonts/*.sf2` 或 `-Dmideditor.soundfont=<路径>` 覆盖；都不可用时退回 JDK 内置 SoundBank（诊断面板会标注后端）。

```powershell
# 从源码构建
mvn clean package
java -jar target\mid-editor-1.0.0.jar
```

Windows 上也可以双击仓库里的 `launch.vbs`（静默启动，jar 缺失时自动先构建）。

## 已知限制

- 音轨的「独立垂直滚动」用音域窗口实现（▲▼ / Alt+滚轮），不额外占用滚动条。
- 频率轴 128 行时每行约 2px，适合总览；编辑建议放大到 24–48 行。
- 循环区间默认取当前选区；无选区时取整个文档。
- 鼓组使用 MIDI 通道 10（Gervill 打击乐映射）。
- 十万级音符的超大工程尚未优化（见上）。
