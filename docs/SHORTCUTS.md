# midEditor 快捷键总表

> 本文件随程序一起打包：菜单 **帮助 → 快捷键** 会用系统默认程序打开它。
> 改快捷键时请同时改代码与本文件（`EditCommands` / `FileCommands` / `PlaybackCommands` / `ViewCommands` / `ArrowKeyDispatcher` / `InputModeDispatcher`）。

---

## 文件

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+N | 新建文档 |
| Ctrl+O | 打开 .mid |
| Ctrl+S | 保存 |
| Ctrl+Shift+S / F12 | 另存为 |
| Ctrl+W | 关闭当前文档 |
| Ctrl+Q | 退出程序 ⚠ 见文末「已知冲突」 |

## 编辑

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+Z | 撤销 |
| Ctrl+Y / Ctrl+Shift+Z | 重做 |
| Ctrl+X / Ctrl+C / Ctrl+V | 剪切 / 复制 / 粘贴（粘贴落点 = 上一次在频谱上点击的位置） |
| Delete | 删除选中的平行线（删完自动选中旁边那条） |
| Ctrl+A | 全选当前音轨 |
| Esc | 取消所有选中（焦点在工具栏 / 传输条上也有效） |
| Ctrl+Q | 量化到网格 ⚠ 见文末「已知冲突」 |
| Ctrl+] / Ctrl+[ | 力度 +10 / −10 |
| Ctrl+T | 在播放头处拆分 |
| Ctrl+Shift+T | 添加音轨 |
| Ctrl+I | 输入模式开关（两态：关 ⇄ 输入模式＋节奏辅助） |
| 无 | 编辑 → 一键移调…（整个文档平移 + 调号跟着转，可顺手换大小调） |

## 音轨

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+Shift+T | 添加音轨 |
| 无 | 音轨 → 删除音轨 |
| 无 | 音轨 → 添加和弦…（类型：三和弦 / 七和弦 / 六和弦 / 挂四 / 五度；位置：上方 / 下方）——以当前音轨为旋律，和弦音写到它下面的新音轨；每点一次都新建一组，不删不改已有音轨 |
| 无 | 音轨 → 音轨上移 / 音轨下移 |
| 无 | 音轨 → 静音 / 独奏 |
| 右键 | 左侧音轨面板右键 = 右键即选中那一条 + 顶部「音轨」菜单同款 |

## 选中与走位

| 快捷键 | 功能 |
| --- | --- |
| ← / → | 在时间上相邻的对象之间走位（换选中对象、试听它、旁边亮 1 秒浮牌）；**没有选中时按 → 先落在起点最早的那条**；输入模式下也能用 |
| ↑ / ↓ | 不参与选中（已禁用，避免上下键走位那种怪感觉） |
| W / S | 选中的平行线整体上移 / 下移半音；**选中的音音高一致时就试听 + 亮 1 秒浮牌**（音高参差的批量移动不发声），输入模式下这两个键归红色光标 |
| A / D | 选中的平行线整体左移 / 右移一格（当前网格分辨率），音高一致时试听 + 浮牌；输入模式下归光标 |
| Alt+↑ / Alt+↓ | 备用键：上移 / 下移半音 |
| Alt+← / Alt+→ | 备用键：左移 / 右移一格 |

## 改长度（选中 ≥1 条时）

| 快捷键 | 功能 |
| --- | --- |
| Alt+Shift+→ / Alt+Shift+← | 整体拉长 / 缩短一格（相邻多条一起按网格伸缩，不留缝） |
| Ctrl+→ / Ctrl+← | 只动选区外边界：右端向右 / 左端向左（外扩） |
| Shift+→ / Shift+← | 只动选区外边界：左端向右 / 右端向左（内收，即缩短） |

## 播放

| 快捷键 | 功能 |
| --- | --- |
| F5 | 播放 / 暂停（桌面窗口里裸 **空格** 同效，输入模式下空格归输入用） |
| F4 | 停止（播放头回到 0，**视野不动**）；备用 Ctrl+空格 |
| F6 | 回到开头；备用 Ctrl+Home |
| Ctrl+L | 循环播放开关 |
| Ctrl+Shift+L | 循环域＝选区 |
| Ctrl+M | 节拍器开关 |

## 视图与缩放

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+= / Ctrl+- / Ctrl+0 | 时间轴放大 / 缩小 / 重置 |
| Ctrl+Alt+= / Ctrl+Alt+- / Ctrl+Alt+0 | 音域（频率轴）放大 / 缩小 / 重置 |
| Ctrl+G | 显示网格开关 |
| Ctrl+K | 键盘标尺开关 |
| Ctrl+Shift+K | Do（C）高亮开关 |
| Ctrl+滚轮 | 音域缩放（以鼠标处音高为锚点） |
| Alt+滚轮 | 时间轴缩放（以鼠标处位置为锚点） |
| Shift+滚轮 | 左右滚动 |
| 裸滚轮 | 频谱上下滚动（在左侧音轨区则滚动音轨列表） |

## 输入模式（Ctrl+I 进入）

| 快捷键 | 功能 |
| --- | --- |
| W / S | 红色光标上移 / 下移半音 |
| A / D | 光标左移 / 右移一格 |
| Ctrl+U / Ctrl+L | 光标整体上移 / 下移一个八度（只挪光标，不出音符） |
| Q（按住） | 试听光标音高，松手停 |
| 空格（按住） | 按下开始计时、松手落成平行线：**按住多久就输入多长** |
| 小键盘 0 | 简谱的 0：休止符（按住多久就留多长的空） |
| 小键盘 1~7 | 简谱 do / re / mi / fa / sol / la / si：按下立刻切到这个音高并开始输入（不用空格） |
| 小键盘 + / − | 八度偏移 ±1，只作用于接下来那个数字，输完一个音自动归零 |
| 按住大键盘 +/= | 紧接着按下的**那一个**数字高一个八度（用完自动回到原八度，不用按反方向键扳回来） |
| 按住大键盘 −/_ | 同上，低一个八度 |
| 大键盘 +（或 −）+ Ctrl + 数字 | 高（低）两个八度，同样只生效一次 |
| Backspace / Delete | 以光标为界按网格删一格（删左 / 删右，Backspace 删完光标左移一格） |
| Esc | 退出输入模式 |

> 每输入一条，新落下的那条自动成为当前唯一选中。
> 进入输入模式时光标接在**最后一个音的末尾**；按住输入（空格 / Q / 小键盘数字）时，按下前光标旁会浮出「音名 + 当前调简谱数字」小牌，松手后停留 1 秒。
> 光标**换到一个新音高**（进入输入模式、W / S、Ctrl+U / Ctrl+L，以及小键盘直接跳音）时，这块小牌也会亮 1 秒；A / D 只挪时间，不弹牌。
> 节奏辅助（工具栏第二个开关）打开后，起点和时值都吸附到当前网格。

## 鼠标

| 操作 | 效果 |
| --- | --- |
| 左键单击平行线 | 选中（并激活它所在的音轨）；单击时试听，并亮 1 秒浮牌 |
| 左键单击平行线右端 6 px 内（不拖） | 同样是单击：选中 + 试听 + 亮牌；只有真的拖动才是改长度 |
| Shift / Ctrl + 左键单击 | 加选 / 取消选中该条 |
| 左键拖动平行线 | 移动（吸附网格；靠近相邻平行线两端时自动贴合）；**选中的音音高一致时**才亮 1 秒浮牌、**不试听** |
| 拖动平行线右端 6 px 内 | 改长度 |
| 空白处左键拖动 | 框选（拖到视口边缘会自动滚动） |
| 空白处单击 | 清空选中（按住 Shift 不清） |
| 双击空白处 | 在点击位置添加一条默认长度的平行线 |
| 拖动播放头竖线（±4 px） | 定位播放位置（拖出视野会跟着自动滚动） |
| 右键 | 上下文菜单（添加 / 拆分 / 休止 / 锁定 / 属性等） |

## 已知冲突

- **Ctrl+Q**：`文件 → 退出` 与 `编辑 → 量化到网格` 都绑了 Ctrl+Q。命令注册表是后注册覆盖先注册，所以实际生效的是 **量化到网格**；「退出」请用窗口关闭按钮或菜单项。
- **Ctrl+L**：平时是「循环播放」；在输入模式里让位给「光标下移一个八度」。
- **Ctrl+= / Ctrl+-**：平时是「时间轴放大 / 缩小」；在输入模式里被当成「按住翻八度」的修饰键，放大缩小请用 Ctrl+Alt+滚轮或退出输入模式。
- **Ctrl+U**：平时无绑定；在输入模式里是「光标上移一个八度」。
- **Esc**：平时是「取消所有选中」；在输入模式里是「退出输入模式」。
- **空格**：平时是「播放 / 暂停」；在输入模式里是「按住输入」。
- 焦点在 BPM / 音轨名等文本框里时，单键与大部分组合键都会让位给文字输入；但 **F4 / F5 / F6 不算文字输入**，照常生效（而且要播时会把 BPM 框里还没回车的数字先提交）。
